AYUKRIPA WELLNESS CARE WEBSITE (DEMO)

FILES
- index.html: HTML, internal CSS and JavaScript in one page.
- assets/: supplied product and logo images.

RUN
1. Extract the ZIP file.
2. Keep the assets folder beside index.html.
3. Double-click index.html or open it in a browser.

IMPORTANT
This is a front-end prototype. Registration records are stored in browser localStorage, and passwords are stored in plain text in this demo. Do not use real customer information or deploy as-is. A production system must use a secure backend, password hashing, HTTPS, a database, account recovery and privacy controls. Generated customer IDs are demo IDs and are not verified against any official network marketing system.
